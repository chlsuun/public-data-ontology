# 국내 공공데이터 제공 서비스 전체를 대상으로 하는 온톨로지 구축 계획

후속 범위 변경: 첨부 명세를 반영한 [v0.3](discovery-platform/README.md)부터 국내외 전 분야를 제품 대상으로 삼는다. 아래 문서는 국내 제공처 조사의 기준·실행 기록으로 유지한다.

범위 수정일: 2026-09-12

실행 결과: [전국 제공처 조사·공통 온톨로지 v0.2 안내](national-catalog/README.md). 공식 출처별 기관 조사 항목 698개를 확보하고, 홈페이지 600곳의 첫 페이지를 탐색해 제공처 후보·기관 입구 122개를 등록했다. 출처 간 중복 기관은 아직 통합하지 않았으며 전국 전수조사 완료 수치가 아니다.

## 목표와 현재 상태

국내 공공데이터 제공 포털과 공식 데이터 제공 서비스를 분야·지역 제한 없이 조사 대상으로 삼는다. 공공데이터포털(data.go.kr)은 여러 출처 중 하나다. 서비스 이름에 '포털'이 없어도 데이터 목록, 통계표, 파일, API, 공간정보 등을 공식적으로 제공하면 조사한다.

기존 model.json과 README.md의 포털 3곳·자료 6개 모델은 구조를 설명하는 시연용 사례다. 전체 서비스의 수집 범위를 나타내지 않는다. 공통 설계·조사 수집기·출처 기록은 national-catalog에 별도로 구현했다. LLM 추천, 개별 자료 API 연결, 전체 자료 목록 수집은 후속 작업이다.

국내를 기본 조사 범위로 해석했다. 국내 서비스에서 제공하는 국제통계는 포함한다. 해외 정부·국제기구가 직접 운영하는 포털의 전수조사는 별도 지리적 범위다.

## 조사 대상의 경계

| 조사 축 | 포함 대상 |
|---|---|
| 중앙 통합 | 국가 차원의 공공데이터 목록과 연계 서비스 |
| 지역 | 전체 광역·기초자치단체의 독립 포털, 공식 누리집 내 데이터 개방 메뉴, 공동 이용 포털 |
| 분야 | 통계·경제·금융·재정·산업·고용·복지·보건·식품·교육·문화·관광·교통·물류·공간·주택·기상·환경·재난·농림·수산·해양·에너지·과학기술·법령·행정·외교안보 등. 이 열거를 폐쇄된 분류 목록으로 사용하지 않음 |
| 기관 | 중앙행정기관, 지자체, 교육기관, 공공기관, 공공 연구기관 등이 운영하거나 공식 제공처로 지정한 데이터 서비스 |
| 서비스 형태 | 통합 카탈로그, 원본 제공 포털, 통계 조회, 지도·공간정보, 문서·연구자료 저장소, 독립 API, 신청형 데이터 제공 서비스 |

공공·민간 자료가 섞인 플랫폼도 조사할 수 있다. 각 데이터셋의 생산·제공 주체와 이용 조건을 별도로 기록하며, 플랫폼에 올라왔다는 이유만으로 모든 자료를 공공데이터로 분류하지 않는다. 신청형 자료는 공개된 설명과 신청 경로를 등록하고 접근 조건을 기록한다.

## '전체'를 조사하는 방법

1. 공식 기관·지자체 목록을 조사 모집단으로 확보하고 기준일과 버전을 기록한다. 정부24 선택항목 98개, 행정안전부 지자체 홈페이지 항목 245개, ALIO 기관목록 355개를 확보했다. 대학·지방공공기관·중앙기관 소속기관의 추가 목록 확보와 출처 간 중복 검토는 진행할 작업이다.
2. 공공데이터포털의 지역별·분야별 안내, 각 기관의 공공데이터 개방 메뉴와 관련 사이트를 통해 서비스 후보를 발견한다.
3. 각 기관에 대해 조사 완료, 조사 중, 미조사 상태를 남긴다. 별도 포털이 없는 기관은 실제 제공처를 기록한다. 검색에서 못 찾은 것을 '없음'으로 확정하지 않는다.
4. 공식 출처, 서비스 명칭, 운영·제공 역할, 현행 주소와 이전 주소를 검토하여 포털 목록에 등록한다.
5. 포털별 전체 목록 획득 방식과 목록 단위, 페이지 처리 방식, 갱신 표시, 접근 조건을 조사한다. 하나의 공통 API가 모든 포털을 포괄한다고 가정하지 않는다.
6. 분야·지역별 미조사 영역과 신규 발견 서비스를 계속 반영한다. 알려진 일부 포털의 목록만으로 전국 전수조사를 완료했다고 표현하지 않는다.

## 포털 조사표의 필수 항목

- 내부 서비스 ID, 공식 명칭, 현재 주소, 이전 주소·별칭
- 운영기관과 공식성 확인 출처; 데이터 생산기관·제공기관은 별도 관계로 관리
- 관할 지역, 다루는 분야, 서비스 역할과 형태
- 목록·상세·API 문서·다운로드 안내 주소
- 목록 수집 방식, 인증 필요 여부, 호출·이용 조건과 해당 근거
- 원문 분류체계, 메타데이터 및 컬럼 설명 제공 여부
- 타 포털 안내·등록·연계 관계와 그 근거
- 공식 안내 확인일, 페이지 확인 상태, 운영 상태, API 실행 확인 상태
- 발견 경로, 검토 상태, 미확인 항목, 다음 조사 작업

페이지를 열 수 있다는 사실과 전체 목록 수집 성공, API 동작, 원본 데이터 최신성은 각각 다른 상태다. 접속 오류는 서비스 종료의 증거로 쓰지 않는다.

## 전체 포털을 수용할 공통 구조

포털 → 등록정보 → 데이터셋 → 배포 파일/API/통계표

데이터셋 → 생산·제공기관 / 주제 개념 / 공간·기간 / 컬럼·측정항목

관계 주장 → 근거 / 확인 상태 / 확인일 / 적용 범위

- 포털의 등록정보와 실제 데이터셋을 구분한다. 같은 자료가 여러 포털에 등록될 수 있고, 포털별 설명·수정일·이용 조건 표시가 다를 수 있다.
- 제목이 같다는 이유로 등록정보나 자료를 합치지 않는다. 원본 ID, 제공 경로, 버전·기간·내용 등의 근거로 동일성 후보를 검토한다.
- '다른 포털로 링크함', '해당 자료를 재등록함', 'API를 중계함', '자료에서 파생됨'을 구별한다. 단순 사이트 링크는 데이터 동기화의 증거가 아니다.
- 포털별 원문 분류체계를 보존하고 공통 개념 사전에 대응시킨다. data.go.kr의 16개 검색 분류를 다른 포털의 모든 개념과 강제로 일치시키지 않는다.
- CSV·엑셀은 컬럼, 통계표는 차원·측정항목, API는 응답 구조·코드, 공간자료는 속성·좌표체계·공간 단위를 정리한다. 문서·영상처럼 컬럼이 없는 자료는 해당없음으로, 구조 정보에 접근하지 못한 자료는 미확인으로 관리한다.
- 의미상 관련성, 결합 후보, 검증된 결합, 특정 분석에서 관찰된 통계적 관계를 서로 다른 관계로 기록한다. 통계적 상관계수는 모든 온톨로지 관계의 필수 근거가 아니다.

## 실행 순서와 완료 기준

| 단계 | 작업 | 검토 가능한 결과 |
|---|---|---|
| 1 | 포털·기관 조사 모집단과 포함 기준 정리 | 기관별 조사 상태와 누락 영역이 있는 포털 조사표 |
| 2 | 전체 포털에 적용할 메타데이터·구조·관계 양식 설계 | 필드 정의, 필수/선택/미확인 처리, 출처·검증 상태 규칙 |
| 3 | 포털별 수집 방법 조사와 수집기 연결 | 목록·상세 획득 방식, 인증·호출 조건, 변경 감지 방식 |
| 4 | 포털별 전체 등록목록·메타데이터 수집 | 출처 ID와 원문을 보존한 통합 목록, 수집 누락·실패 현황 |
| 5 | 전체 자료의 구조 정보 확보와 공통 개념 대응 | 컬럼·차원·코드 사전, 매핑 근거, 미확인·해당없음 상태 |
| 6 | 포털 간 출처 관계·중복 후보·연결 후보 생성과 검증 | 근거와 확인 상태가 있는 관계 목록 |
| 7 | 여러 분야와 여러 포털을 넘는 탐색 평가 | 질문별 근거 있는 추천 결과, 출처·기간·의미 혼동 사례 점검 |

수집과 검증은 포털별로 순차 실행하되 최종 대상에서 특정 분야나 지역을 제외하지 않는다. 실행 순서와 서비스의 전체 범위를 구분한다.

## 진행률

- 기관 조사율: 기준일이 있는 조사 모집단 중 제공 경로 조사를 마친 기관의 비율
- 포털 검토 현황: 발견·공식성 확인·수집 방식 확인·수집 연결 단계별 개수
- 목록 수집률: 포털의 총 등록건수와 집계 단위가 확인된 경우에만 수집 수와 비교. 분모가 없으면 미확인 표시
- 메타데이터 완성도: 확보한 등록정보에서 항목별 누락 비율
- 구조 정보 확보율: 구조화 자료 중 컬럼·차원·응답 구조 등을 확보한 비율. 전체 자료 중 구조화 여부 자체가 미확인인 수를 함께 표시
- 관계 검증 현황: 관계 유형별 확정·검토·후보 개수와 근거 확보 여부
- 갱신 상태: 마지막 수집일, 수집 실패, 신규·변경·이전·종료 확인 이력

현재는 전체 조사 모집단이나 전국 서비스 총수를 확정하지 않았다. 위 초기 목록만으로 '전국 전체 수집 완료' 또는 '전체의 몇 %'라고 보고하지 않는다.
