# 금융통계정보시스템(FISIS) 수집

2026년 9월 14일 금융감독원 [FISIS의 공개 통계표 선택 화면](https://fisis.fss.or.kr/page/fsv101.jsp)에서 금융권역 22개와 분류 경로 241개를 순회했다. 경로별 통계표 출현 1,205건을 보존했고, 중복되는 경로를 묶으면 통계표 식별자 `FORM_NO` 736개다. 과거·현재 양식은 서로 다른 원래 ID와 수록기간을 유지한다. 공식 전체 총계는 확인되지 않았으므로 전국 또는 포털 전체의 수집 완료라는 의미는 아니다.

이 자료가 온톨로지 구축에 유용한 이유는 **항목 이름뿐 아니라 공식 용어 해설과 작성 목적·대상·주기도 제공하기 때문**이다.

예를 들어 다음 정보를 따로 확보한다.

| 종류 | 실제 예시 | 쓰임 |
|---|---|---|
| 포털·게시 기관 | FISIS·금융감독원 | 자료가 어디에서 왔는지 추적 |
| 통계표 | 임직원현황(18.9월 이전), `SDSA001V` | 자료와 양식의 식별 |
| 수록기간 | 1999.06∼2018.09 | 다른 기간·양식과의 차이 확인 |
| 행 항목 | 임원 `A1`, 상임임원 `A11` | 통계표가 구분하는 대상 파악 |
| 공식 용어 해설 | 임원, 상임임원, 총임직원 등의 설명 | 사람이 개념의 의미와 적용 범위를 검토 |
| 작성 정보 | 작성대상·법적 근거·보고주기 | 자료의 해석 조건 확인 |

용어 해설을 같은 이름의 항목에 자동 승인해 붙이지 않는다. 해설에 2018년 이전·이후의 정의가 함께 있는 경우도 있으므로 기간과 대상에 대한 검토가 필요하다. 이름 앞의 들여쓰기와 코드도 원문대로 보존하며, 이를 근거 없이 온톨로지의 상하위 관계로 확정하지 않는다.

통계표의 항목 선택 응답에서 `columnCount`는 알려 주지만 열 이름·정의가 나오지 않는 경우가 있다. 행 항목을 확보했더라도 열 정의는 미해결로 남긴다. 용어 해설과 API 제어 필드를 실제 분석 칼럼 수에 무작정 더하지 않는다.

별도로 [공식 API 설명서](https://fisis.fss.or.kr/page/api-spec.jsp)의 네 기능도 정리했다. 응답 명세 41행, 요청 인자 19행, 서비스명·응답형식 설정 8행이다. `a/b/c/d` 같은 출력 이름은 동적으로 정해지는 열 자리이므로 예제의 ‘임직원수’를 전체 통계표에 적용하지 않는다. API의 `listNo`, 공개 화면의 `FORM_NO`, 금융권역 코드들은 각각의 원래 체계로 저장한다. 인증키가 필요한 Open API는 호출하지 않았다.

사이트의 안내는 금융회사가 제출한 업무보고서에 기초한 자료이며 국가승인통계가 아니라고 설명한다. 이 설명은 출처의 특성으로 기록한다. 신뢰도·결측률·최신성의 임의 점수로 바꾸지 않으며, 실제 통계 관측값은 요청하지 않았다. 일부 메타데이터 페이지의 HTTP 500도 미해결로 보존한다.

- [통계표 항목·해설 수집 진행](fisis-collection-report.json)
- [API 명세 수집 결과](fisis-api-collection-report.json)
- [사이트별 QA](fisis-source-qa.json), [원문 대조](fisis-source-check.json), [DB·HTTP 대조](fisis-import-check.json)
- [로컬 임직원현황 보기](http://127.0.0.1:8766/?record=fisis-SDSA001V)

`collect_fisis.py`는 공개 화면이 실제 사용하는 목록·항목·메타데이터 조회 경로만 허용한다. 원본 관측값 조회와 엑셀 생성 경로는 호출하지 않는다. 이미 저장한 원문·진행을 재사용하며, 실행 중인 수집기는 중복으로 시작하지 않는다. 전체 그래프와 GitHub Pages는 별도의 고정 스냅샷이다.

금융회사 선택 화면은 별도로 16개 권역의 최신 표시 기준월(2026.03)을 조회했다. 선택 항목 1,468행·서로 다른 코드 1,466개를 확보했고, 원문의 분류/집계 노드를 포함한다. 개별 회사 수나 공공데이터 제공기관 수로 합산하지 않는다. [수집 결과](fisis-companies-collection-report.json)와 [전체 원문 대조](fisis-companies-source-check.json)를 보존했으며, 통계표·기관 사이의 데이터 제공 관계를 자동 승인하지 않았다.

자료의 `DATA_TYPE`은 일반적인 DB 자료형과 다를 수 있는 출처 코드다. 공개 화면 코드에서 값 5를 비율 항목 표시로 사용하는 사례를 확인했다. 따라서 이를 정수·문자열 같은 저장 자료형으로 단정하지 않고 `source_data_type_code`에 보존한다. `CAL_UNIT`도 원문 코드를 보존하며 통화나 실제 단위를 추측해 채우지 않는다.

2026년 9월 14일 14:28:44 UTC에 736개 큐의 첫 순회를 마쳤다. 행/열 명세 항목은 19,562개, 원문 용어 해설은 2,707개이며 출처별 반복을 포함한다. 메타데이터 문서는 698개를 확보했고 38개는 HTTP 500이다. 734개 통계표는 응답의 columnCount에 비해 실제 열 정의가 부족하므로 전체 칼럼 완료로 판정하지 않는다. [항목 전체 내보내기](inventory/fisis-audited-columns-snapshot.jsonl.gz)는 API 응답 41행을 포함한 19,603행이며, [용어 해설 내보내기](inventory/fisis-glossary-snapshot.jsonl.gz)는 2,707행을 따로 제공한다.
