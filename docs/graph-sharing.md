## 공유한 범위

2026-09-15 01:13 KST에 만든 고정 그래프 스냅샷이다. 프로토타입 설계에 충분하다고 판단해 대량 수집을 종료한 뒤 최종 등록정보와 명세를 반영했다. [최종 수집 현황과 판단 근거](collection.html)를 함께 볼 수 있다. 전국 전수 수집·의미 관계 검증 완료는 아니다.

모든 등록정보와 원문 항목을 표본 제한 없이 공유 데이터에 넣었다. 각 화면은 24개씩 표시한다. 포털을 선택하면 검색 범위를 줄일 수 있다. 전체 포털의 텍스트 검색은 여러 파일을 읽으므로 시간이 걸릴 수 있고, 진행 상태를 표시한다.

수집한 내용은 **메타데이터**다. 실제 관측값 전체나 원본 다운로드 파일, 기관 내부 DB의 모든 칼럼을 확보했다는 의미가 아니다. 프리뷰 헤더 후보·API 요청 파라미터는 이 그래프 스냅샷의 범위에 포함되지 않는다. 원문 문서와 원본 응답 파일은 로컬에 보관한다.

## 보는 순서

1. **전체 연결**에서 포털 또는 개념을 선택한다. 회색 미수집 후보는 체크박스로 펼칠 수 있다.
2. **출처 경로 펼치기**에서 데이터셋과 원문 항목을 확인한다.
3. **원문 근거 확인**에서 공식 출처 링크·원문 위치·조회 시각·근거 해시를 본다. 원문에 기록되지 않은 속성은 미확인으로 남긴다.
4. **등록 자료**는 개념에 연결되지 않았거나 원문 항목이 0개인 자료도 보여준다.
5. **개념 사전**에서 정의와 의미 검토 조건을 읽는다. 현재 필터·보기·페이지가 URL에 남으므로 해당 주소도 공유할 수 있다.

실선은 수집 결과에서 확인한 소속 연결이다. 점선은 사람이 검토할 의미 연결 후보이며, 확정된 동의어·통계적 상관·인과관계가 아니다.

## 실행·재생성

공유 화면은 `docs/index.html`, 검색기는 `docs/graph-worker.js`이며, `docs/graph-data/manifest.json`에 모든 데이터 조각의 범위·개수·SHA-256이 있다. 최초에는 연결 개요를 읽고 검색할 때 필요한 gzip 파일을 해제한다. 브라우저 검색기는 디코딩한 파일 4개만 캐시한다.

저장소를 내려받아 로컬에서 공유본을 실행하려면 프로젝트 루트에서 다음 명령을 사용한다.

```bash
python -m http.server 8767 --bind 127.0.0.1 --directory docs
```

그다음 `http://127.0.0.1:8767/`을 연다. HTML 파일을 직접 더블클릭하면 브라우저의 파일 접근 제한 때문에 검색기가 동작하지 않을 수 있다.

기존 전체 그래프 DB가 `.local/domestic-catalog/knowledge-graph.sqlite3`에 있는 수집 작업 환경에서는 다음 순서로 공유본을 재생성한다. 재생성은 외부 수집이나 의미 관계 승인을 수행하지 않는다.

```bash
python scripts/build_full_graph_share.py
python scripts/render_full_graph_share.py
python scripts/render_collection_share.py
python scripts/check_full_graph_share.py
```

DB·원문 증거 파일·수집 중간 산출물은 Git에 넣지 않는다. `domestic-catalog` 안의 수집 작업 문서는 로컬 원본·중간 목록을 가리키는 경로를 포함하며, Git에서 바로 조회할 공유 데이터는 `docs/graph-data`에 있다. 공유 데이터의 URL에 인증 파라미터가 있으면 값을 제거하고, 조회 영수증은 공개 출처·시각·상태·해시만 내보낸다. 원자료의 사용 조건은 각 제공처에 따르며 일괄 재사용 승인을 의미하지 않는다.
